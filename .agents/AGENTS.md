## 2. CORE RULE: DO NOT START OR AUTO-SPAWN OLLAMA

```
NEVER call ensure_server_running() automatically.
NEVER set auto_start=True in is_available().
NEVER background-poll Ollama from any scheduler, cron, or startup event.
NEVER try to subprocess.Popen("ollama serve") unless OLLAMA_AUTO_START=true in env.
```

**Why:** Ollama on Windows with local VRAM will crash the entire system if spawned
in the background repeatedly. Ollama must ONLY be used when the USER explicitly
clicks a "Generate" button in the UI. The check timeout must never exceed 1.0 seconds.

**Correct pattern:**
```python
ollama = OllamaAgentBrain()
if ollama.is_available(auto_start=False):
    # proceed with Ollama
else:
    # fall back to Company Intelligence Engine
```

**Manual Start/Stop Button:**
The web TopBar provides an explicit manual `Start Ollama` / `Stop Ollama` button (`POST /api/agentic/ollama-start` & `POST /api/agentic/ollama-stop`).
The user has 100% control over when Ollama is running and can shut it down anytime to free VRAM.

## 3. EMAIL GENERATION RULES (STRICT)

### 3.1 The Fixed Email Template — NEVER CHANGE THIS STRUCTURE

```
Hi [First Name],

[LINE 2 — Generated by Ollama Multi-Agent Pipeline — see Section 4]

Your Company might be thought of some Ai automation to be done in your Day-to-day work , involving from employee management and client acquisition report management or Ticketing Management.
and We provide you the solutions .

If you'd be open to seeing a 2-minute breakdown of how we support teams like [Company], just reply Yes.

Best,
Zoya
ClickfieldAI
```

**Everything except Line 2 is FIXED WORD-FOR-WORD.**
Do not paraphrase it. Do not "improve" it. Do not change punctuation.
The operator has personally approved this exact wording.

### 3.2 Line 2 — What Ollama Must Generate

Line 2 is the ONLY creative output in the entire email.
It must follow this exact sentence pattern:

```
I was reviewing [Company]'s work in [what they genuinely do] and your focus on [their real mission/focus].
```

Ollama must:
- Use real data from the DB (ai_one_liner, value_proposition, service_tags, company_industry, recipient_title)
- Attempt to fetch the company homepage meta/about snippet if website URL is available (max 500 chars)
- Think about what the company ACTUALLY does — not a generic industry category name
- Write a sharp, specific, authentic sentence — NOT corporate fluff
- Keep it to ONE sentence only

BAD examples (never do this):
- "I was reviewing Mitrofresh's work in General Wholesale and your focus on wholesale." — too generic
- "I was reviewing your impressive digital transformation leadership and focus on innovation." — buzzword garbage

GOOD examples:
- "I was reviewing Mitrofresh's work in international wholesale distribution of exotic mushrooms and Asian fresh produce and your focus on delivering high-efficiency cold chain logistics across European markets."
- "I was reviewing Whatif.Works's work in consulting, interim management, and outsourcing for transformational projects and your focus on delivering optimal speed and resource boost with tangible financial victories."

### 3.3 Email Generation is ALWAYS On-Demand

- Generation ONLY happens when the user clicks the Regenerate/Generate button for a specific lead.
- NO batch generation runs in the background.
- NO scheduler generates emails automatically.
- After generation, the draft is saved to outreach_dataset_leads.draft_body and draft_subject.

## 4. THE OLLAMA MULTI-AGENT PIPELINE (For Email Line 2)

When the user clicks Generate, run this sequential 4-agent relay.
Each agent calls Ollama once. They run one after another — never in parallel.

### Agent 1: Company Deep Researcher

```
Role: Research analyst
Input: Company name, website URL, industry, ai_one_liner, value_prop, service_tags, raw_metadata from DB
Task: Synthesize what this company TRULY does in plain English.
      What do they sell, make, distribute, or deliver?
      If website URL is present, fetch the homepage meta description or about text snippet.
Output: A concise 2-3 sentence factual company summary. No fluff. No buzzwords.
```

### Agent 2: Workflow and Friction Spotter

```
Role: Business operations analyst
Input: Agent 1 company summary + industry + recipient job title
Task: Think about where this specific company's day-to-day operations create manual work.
      A wholesale food distributor likely has manual order tracking and dispatch reporting.
      A GP medical practice likely has patient scheduling and referral bottlenecks.
      Focus on employee management, client acquisition reporting, or ticketing bottlenecks.
Output: A one-line operational insight about their main friction area.
```

### Agent 3: Bespoke Copy Synthesizer

```
Role: Outreach copywriter
Input: Agent 1 summary + Agent 2 friction insight
Task: Write ONLY Line 2 of the email.
      Pattern: "I was reviewing [Company]'s work in [what they do] and your focus on [their mission]."
      - One sentence only
      - Specific to this company
      - No buzzwords: never use innovative, cutting-edge, synergy, leverage, empower, seamless
      - Must sound like a sharp human wrote it, not a marketing bot
Output: A single sentence string — Line 2 only.
```

### Agent 4: Quality Auditor and DB Writer

```
Role: Quality gate and persistence layer
Input: Agent 3 Line 2 sentence
Task:
  1. Confirm the sentence follows the "I was reviewing..." pattern.
  2. Confirm it contains the company name.
  3. Confirm no banned buzzwords are present.
  4. If passes — assemble the full fixed email using the template in Section 3.1.
  5. Save draft_subject and draft_body to outreach_dataset_leads WHERE id = lead_id.
  6. Log the generation event to agent_action_audit_log.
Output: Final assembled email saved to DB. Return subject + body + model name.
```

## 7. OLLAMA CLIENT RULES

Always import and use OllamaAgentBrain from app/services/ollama_client.py.

```python
from app.services.ollama_client import OllamaAgentBrain

brain = OllamaAgentBrain()
if brain.is_available(auto_start=False):  # timeout: 1.0s max
    result = brain.generate(prompt, system=system_prompt, format_json=True, temperature=0.3)
```

- Availability check timeout: 1.0 second maximum
- Generation timeout: 60 seconds maximum
- Default model: llama3.2:3b — do not change without explicit user approval
- Never create a second httpx.Client or requests session to hit Ollama directly

## 11. FALLBACK BEHAVIOR WHEN OLLAMA IS OFFLINE

If ollama.is_available(auto_start=False) returns False:
1. Do NOT show an error mid-flow.
2. Fall back to the Company Intelligence Engine using ai_one_liner + value_proposition from DB.
3. Show a soft info message: "Generated using Company Intelligence (Ollama offline)"
4. Save the fallback draft to DB exactly the same as an Ollama-generated draft.
5. User can click Generate again when Ollama is running to upgrade to the LLM version.

## 12. HOW TO ADD A NEW AGENT CORRECTLY

1. Create backend/app/agentic_core/agent_N_name.py
2. Give the class a name property and a clear docstring explaining what it does.
3. All LLM calls must go through OllamaAgentBrain.
4. Register the agent in agent6_workstation_orchestrator.py as self.agent_name = AgentNClass().
5. Add a route in backend/app/api/routes_agentic.py if it needs an API endpoint.
6. Log every action to agent_action_audit_log with: agent_name, action_type, lead_id, company_name, input_summary, output_summary, is_success, execution_time_ms.
7. Update the Section 6 table in this file.
